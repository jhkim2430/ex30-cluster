# EX30 계기판 웹앱
1. GitHub 저장소의 루트에 압축을 푼 파일을 업로드합니다.
2. Settings → Pages → Deploy from a branch → main / root → Save를 선택합니다.
3. 생성된 HTTPS 주소를 아이폰 Safari로 열고 공유 → 홈 화면에 추가를 누릅니다.
4. 처음 실행할 때 위치 접근을 허용합니다.

GPS 속도는 위치 기반 추정치이며 실제 차량 속도계와 차이가 날 수 있습니다. 이 화면은 차량과 연동되지 않으므로 안전 운전 중 실제 계기판을 대체하지 마세요. 배터리 잔량, 기어, 제한속도 표시는 제공하지 않습니다.
